# باکس — قوانین محصول (نسخهٔ قفل‌شده)

> این سند قوانین ثابت محصول را برای نسخهٔ دمو ثبت می‌کند. نام محصول در UI فقط **باکس** است (دامنه: baaxi.ir). در کد و کامنت‌ها «Baax» مجاز است. **ممنوع:** باکسی، Boxx، Baaax، Baaxi.

## هویت برند

- **نام گفتاری/UI:** باکس
- **لوگو:** جعبهٔ باز، آبی–بنفش
- **پالت:** پایهٔ آبی/سفید؛ بنفش **فقط** برای تأکید (CTA، هایلایت). رنگ خطا/تأخیر بنفش **نیست**.

## موقعیت پلتفرم

- باکس **ابزار** است، نه بانک.
- درآمد فقط از **کارمزد**؛ بدون سپرده‌گذاری یا واسطه‌گری مالی واقعی در این دمو.
- هر صندوق **دفترکل جدا** دارد.

## انواع صندوق (دو نوع، فیلدهای UI جدا)

### ۱. قرعه‌کشی (ROSCA)

- یک **برنده در هر دورهٔ ماهانه**.
- فیلدهای UI: مبلغ ماهانه، تعداد اعضا، دورهٔ جاری، وضعیت قرعه، صندلی، تاریخ برداشت، وضعیت پرداخت اعضا.
- برندهٔ دوره **قابل جایگزینی نیست**.

### ۲. پس‌انداز/وام

- فیلدهای UI **جدا:** سقف وام، حق عضویت، قسط ماهانه (هر کدام مستقل).
- بدون امتیاز اعتباری ساختگی (مثل «اعتبار خوبه»).

## تأخیر و جایگزینی

1. **۱۰ روز** اخطار پس از سررسید.
2. سپس جایگزینی صندلی‌های **پیش از برد** پرداخت‌نشده از **لیست انتظار**.
3. جایگزین **بدهی معوق** را می‌پردازد.
4. **برندگان قابل جایگزینی نیستند.**
5. **بدون مصادرهٔ کامل** دارایی.

## وثیقه

- **سفتهٔ الکترونیک** برای همه (مبلغ اسمی پایین).
- **چک** فقط برای صندوق‌های با پات بزرگ.

## خرید زودهنگام (اختیاری، mock)

- شرکا: Snapp Pay، دیجی‌کالا، Tara (شبیه‌سازی).
- در برد: **ابتدا** بدهی به شریک، **سپس** نقد به عضو.

## خارج از محدودهٔ این نسخه

- پنل مدیر/ادمین
- KYC، custody، پرداخت واقعی
- ورود با شمارهٔ تلفن جعلی (در صورت نیاز: یک‌کلیک «ورود دمو»)
